# AeroTwin

A discrete-event digital twin of airport operations, built with Python and SimPy.
It simulates flights through runways, taxiways, stands and turnarounds, and lets
you compare "what-if" scenarios such as fog, runway closure and peak surge.

## Status
Work in progress. Project setup complete.

## Setup (Windows PowerShell)

    python -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt
